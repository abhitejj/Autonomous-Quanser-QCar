# Autonomous Quanser QCar

This repository contains the codebase for running the Quanser QCar in both real-world and virtual (QLabs) environments.

## Structure
- **real_world/**: Scripts and applications to run the physical QCar (e.g., `ssh_setup.sh`, `run_all_cars.sh`, etc.).
- **virtual_world/**: Code for running the QCar in virtual QLabs as a taxi, along with setup scripts (`Taxi.py`, `Setup_Real_Scenario.py`) and required libraries.
